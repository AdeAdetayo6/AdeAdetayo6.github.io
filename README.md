# Wallace Adeleye: portfolio

Live at https://adeadetayo6.github.io

Six case studies on one page, read in order, with a working version of the deal model.
A side index jumps between cases, Listen plays Wallace's own recorded intro (his voice
only, never a computer voice) and a language menu translates the page.

Two projects have their own pages:
- `/carnival/`: the Carnival Sound Map, which works offline after the first visit
- `/investor/`: Our Circle, a rebuilt investor sign-up page (demo only, nothing is sent)

Example figures throughout.
