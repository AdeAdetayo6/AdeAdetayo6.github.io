Case 1 · Financial modelling

A deal model that became a product.

13Linked tabs

Problem

Every property deal was analysed by hand in a new spreadsheet, so results weren't comparable and nothing was reusable.

What I built

  • An Excel model: scenarios, rent-offer grid, break-even rates, scorecard
  • A Python builder that makes the workbook from one config file
  • A What If tab and Power BI tables

Result

It reproduced the original analysis to the penny.

Every new deal now starts from one tested model.

Case 5 · Offline by design

A sound-system map
for a festival with no signal.

37Sound systems and stages pinned
0 BARSNeeded once it’s loaded
1 TAPTo walking directions

Problem

At Notting Hill Carnival, mobile signal all but disappears. The official map is a poster image, so finding a sound system means guessing street corners in a crowd.

What I built

  • The official map with every sound system pinned and searchable
  • Pins calibrated to GPS from the poster’s own tube-station marks, so a blue dot shows where you are
  • One tap hands walking directions to Google or Apple Maps
  • Loads once, then works with no signal

Result

A one-page app that still works when the network doesn’t.

Built for the constraint, not around it.

How I work

“I design the system, set the rules and check the numbers.”

I work backwards from the outcome. Once I know what the project needs, I build the specific tool that moves it forward: a model, a script, a dashboard. I test it against known numbers, then hand it over ready to run. Efficient, direct, and no wasted steps.
